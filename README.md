Computer Networking Basics Documentation

A structured HTML documentation project that explains the fundamental concepts of computer networking in a simple and beginner-friendly format.

Overview

This project was created to provide a clear understanding of how computer networks function, communicate, and maintain security. The documentation is organized into sections covering networking fundamentals, devices, communication protocols, IP addressing, and security concepts.

Features
* Structured documentation-style layout
* Sidebar navigation for easy access to sections
* Beginner-friendly explanations
* Organized learning flow
* Responsive documentation structure
* Pure HTML project

Topics Covered
* Introduction to Computer Networking
* Types of Networks (LAN, WAN, MAN, PAN)
* Network Topologies
* Networking Devices
* Communication Protocols
* OSI Model
* IP Addressing
* Network Security
* Summary & Revision

Technologies Used
* HTML5
